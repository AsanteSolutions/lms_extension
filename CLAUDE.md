# LMS Extension

Frappe app that ships a customised build of the Frappe LMS frontend for Asante's institutes.
Upstream `frappe/lms` is checked out at `../lms`.

To update to a newer upstream LMS, follow [SYNCING.md](SYNCING.md). It lists which files are
upstream copies, what Asante changes and why, and the step-by-step procedure.
